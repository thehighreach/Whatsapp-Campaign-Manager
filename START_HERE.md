# START HERE — High Reach WhatsApp Campaign Manager

## Fastest path

1. Create/configure the High Reach WhatsApp Business Platform account in Meta.
2. Create a Supabase project and run `supabase/schema.sql`.
3. Copy `.env.example` to `.env.local`.
4. Fill all credentials.
5. Run `npm install`.
6. Run `npm run dev`.
7. Create and get approval for the marketing template in `docs/TEMPLATE_COPY.md`.
8. Test using your own opted-in WhatsApp number.
9. Deploy to Vercel and configure the webhook using `docs/META_SETUP.md`.
10. Only then import real opted-in leads and start small campaigns.

Read `docs/META_SETUP.md` for the complete step-by-step process.

For going live (real number, payment, Vercel, webhook, `subscribed_apps`, Live mode), follow `docs/PRODUCTION_SETUP.md`.
